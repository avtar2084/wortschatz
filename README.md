# Wortschatz

English → German active-recall vocabulary trainer (A1–B2), installable as a PWA.

Open the GitHub Pages URL in Safari on iPhone → Share → Add to Home Screen. Works offline after the first load. Progress is stored locally on the device.

Vocabulary: a 108-word A2 sample based on the Goethe-Zertifikat A2 Wortliste. It is not the complete list.

Source: `index.html` is built from `../wortschatz.html` by `../build-pwa.sh`.
